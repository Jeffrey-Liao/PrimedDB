"# Repository Guidelines" 
"## Project Structure & Module Organization" 
"" 
"This is a C++ database system project organized as follows:" 
"- `PrimedDB/source/` - Core implementation files (*.cpp)" 
"- `PrimedDB/header/` - Header files (*.h)" 
"- `PrimedDB/source/test/` - Unit test files" 
"- `PrimedDB/data/` - Database data files" 
"- `PrimedDB/log/` - Application logs" 
"## Build, Test, and Development Commands" 
"" 
"Build using Visual Studio solution:" 
"- Open `PrimedDB.sln` in Visual Studio 2022" 
"- Build solution (Ctrl+Shift+B) or use MSBuild" 
"- Run `TestMain.cpp` for testing functionality" 
"## Coding Style & Naming Conventions" 
"" 
"- Class naming: PascalCase (e.g., `TableManager`, `UserManager`)" 
"- File naming: ClassDef.cpp pattern for implementations (e.g., `TableDef.cpp`)" 
"- Use `USESTD;`, `USELIAO;` macros for namespace inclusion" 
"- Follow existing code patterns in header/source pairs" 
"## Testing Guidelines" 
"" 
"- Place test files in `PrimedDB/source/test/` directory" 
"- Test naming: `[ClassName]TestDef.cpp` pattern (e.g., `ErrorManagerTestDef.cpp`)" 
"- Use `TestMain.cpp` for integration testing and manual testing" 
"## Commit & Pull Request Guidelines" 
"" 
"- Commit messages: Use descriptive, concise format" 
"- Examples: \"created test to ErrorManager\", \"improved timestamp class\"" 
"- Pull requests: Follow feature branch naming pattern (e.g., `feature-name`)" 
"- Ensure code compiles and tests pass before PR submission"
